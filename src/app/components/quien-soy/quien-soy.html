Mi juego: Compatibilidad 💖

Este juego fue elegido por ser un recuerdo de mi infancia, simple, divertido y busca generar interacción inmediata.

Se basa en calcular el nivel de compatibilidad entre dos nombres de forma aleatoria.

El resultado se genera de forma aleatoria, lo que permite que cada intento sea único y sorprendente.

¿Cómo jugar?
  • Ingresar dos nombres
  • Presionar calcular
  • Ver el resultado
